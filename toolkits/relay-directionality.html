Polarization Methods: Choose how the relay determines direction.

V1 Pol / I1 Op

Positive sequence voltage (V1) polarizes, positive sequence current (I1) operates.

This is the standard method for phase fault detection. It works by comparing the angle between positive sequence voltage and current.

When I1 is within ±90° of V1 (adjusted by MTA), the relay determines forward direction.

(-3V0) Pol / (3I0) Op

Zero sequence voltage (-3V0) polarizes, zero sequence current (3I0) operates.

This is the primary method for ground fault detection. The negative sign on -3V0 aligns the polarizing quantity with expected fault direction.

The factor of 3 compensates for the sequence network calculations, making quantities comparable to phase values.

V2 Pol / I2 Op

Negative sequence voltage (V2) polarizes, negative sequence current (I2) operates.

Used for sensitive ground fault detection and specific unbalanced fault conditions.

More sensitive than zero sequence for some ground faults and can detect high-resistance faults.

Vbc Pol / Ia Op

Quadrature voltage (Vbc = Vb-Vc) polarizes, phase A current (Ia) operates.

Common for phase distance elements, providing memory voltage during close-in faults.

The quadrature relationship (90° shift) between Vbc and Ia in normal system conditions provides good discrimination.
