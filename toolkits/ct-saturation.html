Slider Variables Explanation

System Parameters

  • Peak Current (A): Sets the maximum amplitude of the primary current (in amperes) used in the simulation.
  • Burden (Ω): Determines the resistance connected to the CT secondary; it affects the secondary voltage.
  • DC Offset (x peak): Applies a DC offset (as a fraction of the peak current) to the current waveform.
  • X/R Ratio: The ratio of the CT's reactance to resistance, impacting the decay rate of the DC component.
  • Number of Cycles: Specifies how many 60 Hz cycles are simulated.
  • Phase Angle (°): Adjusts the phase shift of the primary current waveform from 0° to 360°.

Core Parameters

  • Volt-Sec Rating: The rated voltage-second product of the CT core, reflecting its magnetic capacity.
  • Linear Region (%): The percentage of the core's flux range over which the CT behaves linearly.
  • Linear Slope (%): Indicates the proportional response (slope) of the CT in its linear operating region.
  • Saturation Factor: Defines the rate at which the CT response increases beyond the linear region, simulating core saturation.
  • Remanence (Volt-Sec): The initial flux in the core at time zero, simulating residual magnetism from a prior event.
  • Surge Impedance Loading (SIL)
